\# Beecrowd 1061 - Tempo de um Evento



\## Descrição



Este programa resolve o problema 1061 do Beecrowd.



\## Tecnologias utilizadas



\- Java

\- NetBeans

\- Maven



\## Entrada



A entrada contém o dia, a hora, os minutos e os segundos de início e de término do evento.



\## Saída



O programa apresenta a duração do evento em dias, horas, minutos e segundos.
